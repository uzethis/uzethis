How are exceptions counted?

Changed, missing and new counts are record-level counts. Duplicate count is the number of extra rows beyond the first occurrence of each repeated ID, counted separately in each file. A row can appear in more than one exception category. Blank IDs are reported as duplicates/invalid IDs because they cannot be reliably matched.
