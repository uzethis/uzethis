CSV Reconciliation Checker

A free, browser-based tool for comparing two CSV files and identifying discrepancies.

How to use

1. Select the master CSV file.
2. Select the new report CSV file.
3. Choose the record ID column in each file.
4. Compare records and review the results.
5. Download the exception report as a CSV.

Exception types

- Changed: A matching ID has different field values.
- Missing: A record exists in the master but not in the new report.
- New: A record exists in the new report but not in the master.
- Duplicate: A record ID appears more than once in either file.

Privacy

Files are processed locally in your browser. The tool does not intentionally upload file contents to a server.

Limitations

- CSV files only; Excel workbooks are not supported in this version.
- Records are matched using exact IDs.
- Only columns with matching names can be compared.
- Review results before making business or financial decisions.
